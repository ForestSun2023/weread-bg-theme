给微信读书网页版阅读页补上**手机 App 才有的背景功能**：白天 3 套底色 × 5 种纸张纹理 = **15 种组合**，另加一个全屏阅读按钮。

> **非官方脚本，与腾讯 / 微信读书无任何关联。**
> 它只在**你自己的浏览器**里改显示样式 —— 不发任何网络请求、不上传任何数据、
> 不碰你的书架、笔记和阅读进度。

![背景面板](https://raw.githubusercontent.com/ForestSun2023/weread-bg-theme/main/screenshots/%E9%9D%A2%E6%9D%BF.png)

面板三块：**亮度滑杆**、**颜色**（3 套）、**背景**（5 种纹理），下面是恢复默认。

## 功能

| | |
|---|---|
| **底色** | 白 `#f8f8fa` · 米黄 `#f5efd9` · 青绿 `#c0edc6` |
| **纹理** | 纯色 · 纸纹 · 素纸 · 云 · 月 |
| **组合** | 3 × 5 = **15 种**，底色与纹理自由搭配 |
| **黑夜** | **整块交还官方原装外观**，脚本一点都不碰 |
| **另加** | ⛶ 全屏阅读按钮 |

![15 种组合全览](https://raw.githubusercontent.com/ForestSun2023/weread-bg-theme/main/screenshots/%E4%B8%BB%E9%A2%98%E7%9F%A9%E9%98%B5.jpg)

三套底色是从**官方手机版截图逐像素采样**得到的，不是凭感觉调的：
半透明叠加层的取值是**算出来的** —— 底色记 `B`、官方实测记 `T`，
层用 `alpha = 0.5` 时合成结果是 `0.5×层 + 0.5×B`，所以 **层 = 2T − B**。

## 使用

装好后打开任意一章（`https://weread.qq.com/web/reader/...`），
**把鼠标移到页面中间** —— 右侧工具条平时隐藏，移上去才浮出来。

工具条最下方是本脚本的按钮（固定在所有原生按钮之后）：

| 按钮 | 作用 |
|---|---|
| **☀ 背景** | 打开 / 关闭背景面板（**只在白天出现**） |
| **⛶ 全屏阅读** | 全屏 / 退出全屏，图标与提示跟着状态切换 |

- 快捷键 **`b`** 开关面板（在输入框 / 写想法的地方不会误触发），`Esc` 或点面板外的遮罩关闭
- **设置自动保存**，换页、刷新、重开浏览器都还在

### 控制台 API

在阅读页按 `F12` → Console：

```js
wrbg.set({ colorId: 'sepia', bgId: 'paper', brightness: 0.9 })
wrbg.state        // { colorId, bgId, brightness }
wrbg.reset()
wrbg.colors       // ['white','sepia','green']
wrbg.backgrounds  // ['solid','paper','plain','cloud','moon']
wrbg.dark         // 当前是不是黑夜（黑夜下脚本整块让位）
```

## ⚠️ 白天 / 黑夜怎么分工

**一句话：脚本只管白天；一进黑夜就整块让位，只多一个「全屏」按钮。**

| | 底色 / 正文 / 位图 / 弹层 | 「背景」按钮 | 「全屏」按钮 |
|---|---|---|---|
| **白天** | 全部由脚本画 | 显示 | 显示 |
| **黑夜** | **官方原装，脚本一点都不碰** | 隐藏 | 显示 |

**昼夜切换请用站点原生的「深色」按钮**（工具条上那个月亮图标），本脚本故意不自己造这个开关。

原因：阅读器的正文有一部分是引擎**光栅化进 `<canvas>` 的位图**，字色在绘制那一刻就烤进像素里了。
只翻一个 CSS 类**不会通知引擎重绘** —— 从黑夜切回白天时，引擎还以为在黑夜、继续按浅色画字，
而浅色纸底已经铺上去，两者一叠就成了「浅色字压在浅色纸上」，几乎看不见。
站点原生的按钮走的是引擎自己的状态，重绘时机才是对的。

## 封号风险

脚本的行为边界很清楚：

**会做的** —— 插一个 `<style>` 用 CSS 变量覆盖底色 / 正文色 / 顶栏 / 弹层配色；
往工具条插两个按钮；往 `localStorage` 写一个键（只存配色、纹理、亮度）。

**不会做的** —— 无 `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon`；
无 `eval` / `new Function`；无 `@require` / `@connect` / `GM_*`（本脚本 `@grant none`）；
不碰 `document.cookie`、不碰框架内部对象；无 `.click()` / `dispatchEvent` 等模拟操作。

也就是说：**不产生任何可被服务端观测的异常流量。**

## 已知限制

- **官方纹理其实是照片**：放大官方截图能看到「云」的底部是一张雪山照片、「月」是带环形山的真实月球照片。
  CSS 渐变只能还原**位置、大小、亮度和明暗走向**，还原不出山脊和环形山
- **不碰排版**：边距、行距、段间距、首行缩进都没有 —— 阅读引擎没有暴露这些参数
- **黑夜下没有背景功能**（刻意的，见上文分工）
- **不支持自定义图片背景** —— 那样就得引入外部资源，脚本不再是单文件离线可用，亮度滑杆也会失效
